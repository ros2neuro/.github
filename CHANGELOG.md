## ros2neuro

This organization hosts the ROS 2 packages for the ros2neuro ecosystem.

## Temporary changelog

This list is used temporarily to track changes made across the organization repositories.

- 2026-11-12 [PaoloFori] **docs**, **ros2neuro_devel_test**: The MATLAB download works on its own: `ros2neuro_matlab.zip` carries `reference/` (the first 512 samples of the input and of the ROS 2 output of every filter, and a test model), so `check_functions` runs all 21 checks; the new `ros2neuro_matlab_example.zip` is one recorded evaluation (GDF, CSV of every topic, yaml and model), so `check_evaluation` redoes the whole chain without ROS 2. `check_evaluation` takes the launcher folder as a third argument.
- 2026-11-12 [PaoloFori] **ros2neuro_recorder_xdf**: `xdf_recorder.launch.py` passed `output_directory` and `max_pending_frames`, which the recorder does not read: the arguments are now `output` (folder of the file) and `max_queue_size`, and the file is no longer always written in the working directory. The integration test places its event with `header.stamp` (the recorder positions events by stamp, not by `onset`).
- 2026-11-12 [PaoloFori] **ros2neuro_acquisition_dummy**: The sinusoids are continuous across frames (before, every frame restarted from phase 0).
- 2026-11-12 [PaoloFori] **ros2neuro_devel_test**: `mi_loop.launch.xml` used an undeclared `config_file` argument (it is `config`).
- 2026-11-12 [PaoloFori] **ros2neuro_decoder_sklearn**: New package. Decoder plugin `ros2neuro::decoder::Sklearn` for scikit-learn models (any estimator or Pipeline with `predict_proba`, saved with skops), run inside the C++ decoder node (embedded Python), configured like every decoder with `decoder.manifest`. Axes matched by label / value, `features.mode: all | selection`, output in the order of `output.fields`. Example model (StandardScaler + LDA on the PSD of test.gdf) and its training script; tests against `predict_proba`.
- 2026-11-12 [PaoloFori] **ros2neuro_devel_test**: New launchers `sklearn_bars` / `sklearn_wheel` (made-up LogisticRegression on a selection of features) and `sklearn_4class_bars` (fictitious 4-class RandomForest), the gaussian chain with the scikit-learn plugin; models written by `scripts/make_sklearn_models.py`.
- 2026-11-12 [PaoloFori] **ros2neuro_decoder_braindecode**: New package. Decoder plugin `ros2neuro::decoder::Braindecode` that runs a braindecode (PyTorch) model inside the C++ decoder node (embedded Python, pybind11). It reads the model folders of `ros2neuro_decoder_py` (given with `decoder.manifest`, like every decoder; braindecode manifests now have `type: ros2neuro::decoder::Braindecode`, the old `EEGClassifier` moved to `wrapper`) and gives the same probabilities (956 predictions of a whole run, difference 0). Tests against the output of the Python node.
- 2026-11-12 [PaoloFori] **ros2neuro_decoder**: The node reads only `decoder.name` and `decoder.type` of the manifest (the type picks the plugin); the plugin reads and checks the rest, so every decoder, spectral or deep-learning, is configured the same way (`decoder.manifest`). The plugin parameters `decoder.params.*` given in the launch file or yaml now reach the plugin (they were never declared, so the plugin got none of them).
- 2026-11-12 [PaoloFori] **ros2neuro_devel_test**: The `eegnet*` launchers have `decoder:=plugin` (default, the braindecode plugin) or `decoder:=python` (the node of `ros2neuro_decoder_py`).
- 2026-11-12 [PaoloFori] **ros2neuro_manager**, **ros2neuro_control_feedback**, **ros2neuro_feedback**: `event.shown` must be a power of two (the display events are recognised by its bit); the feedback now validates the event ids like the manager and control.
- 2026-11-12 [PaoloFori] **ros2neuro_filters_laplacian**: The layout is refused at configure when an id is below 0 or above `nchannels`, and a frame with a number of channels other than `nchannels` is dropped with a clear error (before, both read or wrote out of the mask).
- 2026-11-12 [PaoloFori] **ros2neuro_decoder**: A missing or malformed `manifest.yaml` makes the node log the reason and exit with 1 (before, an uncaught exception aborted it).
- 2026-11-12 [PaoloFori] **ros2neuro_processing_buffer**: Source formatted for `ament_uncrustify` (no change of behaviour).
- 2026-11-12 [PaoloFori] **All packages, docs**: READMEs and documentation pages checked against the code and corrected (parameters, defaults, launch arguments, messages, examples that did not compile or configure).
- 2026-11-12 [PaoloFori] **ros2neuro_feedback_bar**: At the end of a trial that ended in a Timeout every bar keeps its color but paler (mixed with white) until the boom ends, as if it went to the background (the wheel does the same with its arc); before, the bars showed nothing for a Timeout. Hit and Miss are unchanged (the bar that was reached lights up).
- 2026-11-11 [PaoloFori] **ros2neuro_devel_test**: Fixed the launchers with the rest (`gaussian_rest_{bars,wheel}`, `gaussian_4class_rest_bars`, `eegnet_rest_{bars,wheel}`): the feedback loaded the layout without the rest, so it drew neither the cue of the rest nor the yellow dot of a rest that ends without touching a threshold. New `scripts/check_launch_layouts.py` checks that control, manager and feedback load the same layout in every launcher.
- 2026-11-11 [PaoloFori] **ros2neuro_control_feedback**, **ros2neuro_control**: The plugin is now `ros2neuro::control::Feedback` (was `ros2neuro::control_feedback::Feedback`): update the `plugin` parameter of the control node. Its internal classes moved to `ros2neuro::control::feedback`. Parent and plugins now share the namespace `ros2neuro::<family>` in every family.
- 2026-11-11 [PaoloFori] **ros2neuro_manager**, **ros2neuro_manager_synchronous**, **ros2neuro_manager_asynchronous**, **ros2neuro_feedback**, **ros2neuro_feedback_wheel**, **ros2neuro_feedback_bar**: The base classes are renamed `ros2neuro::manager::Manager` (was `ManagerPlugin`) and `ros2neuro::feedback::Feedback` (was `FeedbackPlugin`). The plugin ids (`Synchronous`, `Asynchronous`, `Wheel`, `Bar`) do not change; the header file names do not change.
